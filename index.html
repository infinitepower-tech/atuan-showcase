02 · AI 是什么

模型、工作台、Agent
用开电动车来理解

听到一堆名字别慌：它们其实分属不同的「层」。记住下面四个比喻就够了。

⚡
TOKEN / API KEY
Token=电

AI 的能源，按用量计费。Infinite Power 负责稳定供电，一串 Key 插到哪都能用。

🧠
LARGE MODEL
大模型=发动机

决定 AI 有多聪明。GPT、Claude、DeepSeek 就是不同品牌的发动机。

🖥️
WORKBENCH
工作台=驾驶舱

方向盘在你手里：你问一句，它答一句。发动机可以随时换。

🤖
AGENT
Agent=自动驾驶

说出目的地就行：它自己规划、动手、交付结果，你负责验收。

一句话串起来：你坐进驾驶舱（工作台）自己开，或者交给自动驾驶（Agent）；车能跑多快看发动机（大模型）；而所有车都得充电（Token）——这就是 Infinite Power 在做的事。

常见疑问

我买的 Token 属于哪一层？

属于最底层的「电」。同一串 API Key 可以插进任何一个工作台或 Agent，换软件不用重新买。

ChatGPT 网页版、豆包 App 算哪层？

那是官方把发动机 + 驾驶舱打包好的「整车」。我们的做法是：自己挑顺手的驾驶舱，接上 Infinite Power。

新手先用哪个？

先装一个工作台（Cherry Studio / Chatbox）练手；熟悉后再上 Agent（Codex）让它直接帮你干活。
